## Discipline rules (when tired in the morning)

1. **Do not negotiate away the whole session** because the previous days went well.
2. **“Weekend catch-up” is banned** — today’s slot is today’s slot.
3. **Tired ≠ skip:** minimum = show up, warm up, **one main lift or 20 min** + leave. Log it.
4. **True rest** (fatigue, ache, poor sleep ×2) = use morning gate in `recovery-routine.md` — **not** the same as discipline skip.
5. **End of day:** `/journal` or Telegram `/journal` — even rest days, even “I missed.”

## After a miss

| Misses | Action |
| ------ | ------ |
| **1** | Next morning: **non-negotiable** gym. Journal why. |
| **2** | Same + check sleep/food; no doubling volume to “punish.” |
| **3+** | Reset: pick **next single session** (Push B or Push A), book swim separately, journal the pattern — **no shame spiral**. |
