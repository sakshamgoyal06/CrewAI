# Recovery routine (locked)

**Purpose:** Prevent burnout when restarting training after a long gap. Rest is **program adherence**, not failure.

_Last locked: 2026-07-16 — after 3 consecutive gym days (Push A → Pull A → Cardio+Abs) and skipped Push B due to fatigue + muscle ache._

---

## Weekly rhythm (default)

| Day | Session | Notes |
| --- | ------- | ----- |
| 1 | **Push A** | Strength |
| 2 | **Pull A** | Strength |
| 3 | **Cardio + Abs** | Lighter, but still taxing when cumulative fatigue is high |
| 4 | **REST** | Mandatory buffer before second push day |
| 5 | **Push B** | Only if return criteria met (below) |
| 6 | **Pull B** | Strength |
| 7 | **Legs** | Strength |
| — | **REST** | At least 1 full rest day per 7 days; 2 if energy is low |

**Hard rule:** **No more than 3 gym days in a row** without a rest day. Cardio day counts — it is not “easy” when you are already sore from Push + Pull.

---

## Morning gate — train or rest?

Answer honestly before leaving for the gym:

| Signal | Train | Rest |
| ------ | ----- | ---- |
| Energy on waking | Normal / good | **Very tired**, heavy limbs |
| Muscle ache | Mild DOMS, moving OK | **Widespread ache**, stiff, dreading compounds |
| Sleep last night | Reasonable | **Poor** (2nd night in a row = rest) |
| Consecutive gym days | ≤ 2 since last rest | **3+** since last rest |
| Mood toward session | Willing | **Dreading it** / forcing |

**If 2+ rest-column signals → rest day.** No negotiation needed.

## Rest day protocol (do this)

Rest means **no gym session** — not “skip everything.”

### Must-do (15–30 min total)

1. **Sleep** — prioritize tonight; aim for an extra 30–60 min if possible.
2. **Food** — eat on schedule; **protein at lunch** helped recovery on 15 Jul. Don’t skip meals because you didn’t train.
3. **Hydration** — water through the day; light if dinner was heavy.
4. **Gentle movement** — **10–15 min easy walk** (not cardio finisher intensity). Optional: **5 min light stretch** (same post-gym habit — chest, lats, hips).

### Optional (only if it feels good)

- Foam roll / mobility — sore spots only, no pain chasing.
- Nap 20–30 min if very tired.
- Steps at easy pace — not a step-count chase.

### Do not

- “Make up” with extra cardio, jumping jacks, or abs at home.
- Train Push B “lightly” — partial sessions extend fatigue without quality stimulus.
- Shame-spiral on nutrition because you rested.

---

## Return-to-gym criteria (before Push B)

All should be **yes** before the next strength day:

- [ ] Woke with **acceptable energy** (not perfect — just not “very tired”).
- [ ] Muscle ache **eased** — DOMS OK; whole-body wipeout is not.
- [ ] **At least 1 full rest day** since last gym visit.
- [ ] **Willing** to do compounds with focus (not dragging through it).

If still very tired tomorrow → **second rest day** is correct. Push B will wait; the split is flexible.

---

## Training-week modifiers (burnout prevention)

1. **After Cardio + Abs** — default **rest next day** (learned 16 Jul).
2. **Treadmill finisher** — 15 min when fatigued is fine; don’t extend session to “make up.”
3. **Post-session stretch** — keep **~3 min minimum** even when tired (helped 13–14 Jul).
4. **Late sessions** — queue video/podcast **before** gym; expect shorter finisher.
5. **Sleep** — treat as a training input; less-than-ideal sleep + 3 gym days = rest.
